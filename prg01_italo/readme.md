# Hyperpes

Um sistema de pesquisa para diferentes perfis geracionais de auto-adaptação para uma melhor interação na resolução do problema.

## Estrutura do projeto

- `index.html` — página principal do site
- `assets/css/` — arquivos de estilo (CSS)
- `assets/js/` — scripts JavaScript
- `assets/images/` — imagens do site, incluindo o favicon
- `assets/fonts/` — fontes customizadas usadas no projeto
- `components/` — componentes reutilizáveis (ex: header, footer, menu)
- `pages/` — páginas internas do site
  - `pages/about/` — página "Sobre"
  - `pages/contact/` — página "Contato"

## Como executar

Abra o arquivo `index.html` (dentro de `pages/`) no navegador, ou use uma extensão como o Live Server no VSCode.
